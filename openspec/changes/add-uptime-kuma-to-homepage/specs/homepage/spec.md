## ADDED Requirements
### Requirement: Uptime Kuma Widget
The homepage SHALL display a Uptime Kuma widget showing real-time uptime status for homelab services.

#### Scenario: Uptime Kuma widget displays status
- **WHEN** user visits the homepage
- **THEN** Uptime Kuma widget is shown with uptime information
- **AND** widget links to https://uptime.simonbrundin.com
